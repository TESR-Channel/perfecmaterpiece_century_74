# เว็บยืนยันข้อมูลลูกบ้าน — หมู่บ้านเพอร์เฟค มาสเตอร์พีซ เซ็นจูรี่

เว็บหน้าเดียว ใช้งานได้ทั้งมือถือ iPhone, iPad, Android และคอมพิวเตอร์
ประกอบด้วย 2 ขั้นตอน: ให้ความยินยอม PDPA → กรอกข้อมูล แล้วบันทึกลง Google Sheets

## ไฟล์ในชุดนี้

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | ตัวเว็บไซต์ทั้งหมด (อัปโหลดขึ้น GitHub) |
| `line-qr.png` | QR Code LINE Official (แสดงหลังบันทึกสำเร็จ) |
| `map-thumb.jpg` | ภาพแผนผังย่อ แสดงในหน้ากรอกข้อมูล |
| `map-full.jpg` | ภาพแผนผังเต็ม เปิดในป๊อปอัปเมื่อกดที่ภาพ |
| `Code.gs` | โค้ดสำหรับวางใน Google Apps Script |
| `README.md` | คู่มือนี้ |

---

## ขั้นตอนที่ 1 — สร้าง Google Sheets ที่จะเก็บข้อมูล

1. สร้าง Google Sheets ใหม่ ตั้งชื่อ เช่น "ทะเบียนลูกบ้าน"
2. บนแถบเมนู เลือก **ส่วนขยาย (Extensions) → Apps Script**
3. ลบโค้ดเดิมทั้งหมดในหน้าจอ แล้ววางเนื้อหาจากไฟล์ `Code.gs` ลงไป
4. กดบันทึก (รูปแผ่นดิสก์)

## ขั้นตอนที่ 2 — เผยแพร่ Apps Script

1. มุมขวาบน กด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้ใหม่ (New deployment)**
2. กดรูปเฟือง เลือกประเภท **เว็บแอป (Web app)**
3. ตั้งค่าดังนี้ (สำคัญมาก)
   - ดำเนินการในฐานะ (Execute as): **ฉัน (Me)**
   - ผู้ที่มีสิทธิ์เข้าถึง (Who has access): **ทุกคน (Anyone)**
4. กด **ทำให้ใช้งานได้** แล้วกดอนุญาตสิทธิ์ตามที่ระบบถาม
   (ถ้าขึ้นเตือน "Google ยังไม่ได้ตรวจสอบแอปนี้" ให้กด ขั้นสูง → ไปที่โปรเจ็กต์ (ไม่ปลอดภัย) — เป็นเรื่องปกติของสคริปต์ที่เราเขียนเอง)
5. คัดลอก **URL ของเว็บแอป** ที่ลงท้ายด้วย `/exec`

## ขั้นตอนที่ 3 — ใส่ค่าลงในเว็บ

เปิดไฟล์ `index.html` มองหากล่อง `const CONFIG = {` ที่อยู่ด้านบนสุด แล้วเติมค่า

```js
scriptUrl:    "วาง URL /exec ที่คัดลอกมา",
pdpaPdfUrl:   "pdpa.pdf",              // ใส่ทีหลังได้ เมื่อมีไฟล์ PDF ฉบับจริง
lineUrl:      "https://lin.ee/TN8LooM", // ใส่ไว้ให้แล้ว
contactPhone: "02-xxx-xxxx",
houseNumbers: { prefix: "112/", from: 156, to: 307 },  // ช่วงเลขที่บ้านในรายการให้เลือก
requireEmail: false                    // เปลี่ยนเป็น true ถ้าต้องการบังคับกรอกอีเมล
```

## ขั้นตอนที่ 4 — อัปโหลดขึ้น GitHub Pages

1. สร้าง Repository ใหม่ (ตั้งเป็น Public)
2. อัปโหลด `index.html`, `line-qr.png`, `map-thumb.jpg` และ `map-full.jpg` ไว้ที่ชั้นนอกสุด (ต้องอยู่โฟลเดอร์เดียวกันทั้งหมด)
3. ไปที่ **Settings → Pages** → Source เลือก **Deploy from a branch** → branch `main` โฟลเดอร์ `/ (root)` → Save
4. รอประมาณ 1–2 นาที จะได้ลิงก์หน้าตาแบบ `https://ชื่อผู้ใช้.github.io/ชื่อ-repo/`
5. นำลิงก์นั้นไปทำเป็น QR Code หรือส่งในกลุ่มลูกบ้านได้เลย

## ขั้นตอนที่ 5 — ทดสอบ

กรอกข้อมูลทดสอบ 1 ชุด แล้วเปิด Google Sheets ดูว่ามีแถวข้อมูลเพิ่มขึ้นหรือไม่
ถ้าไม่ขึ้น ให้ตรวจว่าตอน Deploy ตั้ง "ผู้ที่มีสิทธิ์เข้าถึง" เป็น **ทุกคน** แล้วจริง ๆ

---

## เมื่อได้ไฟล์ PDF ของ PDPA ฉบับจริงแล้ว

1. อัปโหลดไฟล์ (ตั้งชื่อ `pdpa.pdf`) ขึ้น GitHub โฟลเดอร์เดียวกับ `index.html`
2. แก้ `pdpaPdfUrl: "pdpa.pdf"` ในไฟล์ `index.html`
3. ปุ่ม "เปิดอ่านเอกสารฉบับเต็ม (PDF)" จะปรากฏขึ้นอัตโนมัติ และข้อความหมายเหตุ "ตัวอย่างชั่วคราว" จะหายไป

ส่วนข้อความ PDPA ที่แสดงบนหน้าเว็บ สามารถแก้ไขได้ในไฟล์ `index.html`
ที่บริเวณ `<div class="doc" id="pdpaDoc">` (แก้เป็นข้อความจริงได้ตามต้องการ)

## แผนผังโครงการในหน้ากรอกข้อมูล

ด้านบนของหน้ากรอกข้อมูลมีภาพแผนผังโครงการขนาดย่อ กดที่ภาพแล้วเปิดเป็นป๊อปอัปเต็มจอ
มีปุ่ม "ขยายภาพ +" สำหรับเลื่อนดูเลขที่บ้านชัด ๆ ปิดได้ด้วยปุ่มปิด กดพื้นหลัง หรือปุ่ม Esc
บนมือถือใช้สองนิ้วถ่างขยายได้ตามปกติ

ถ้าต้องการเปลี่ยนภาพแผนผังในอนาคต ให้แทนที่ไฟล์ `map-thumb.jpg` และ `map-full.jpg` ด้วยชื่อเดิม

## เลขที่บ้าน — เป็นรายการให้เลือก ไม่ต้องพิมพ์เอง

ระบบสร้างรายการ **112/156 ถึง 112/307** (รวม 152 หลัง) ให้กดเลือก จึงไม่มีทางพิมพ์ผิดหรือพิมพ์คนละรูปแบบ
บนมือถือจะเด้งเป็นวงล้อเลื่อนเลือกของ iPhone/iPad หรือ Android โดยอัตโนมัติ

ถ้าต้องการเพิ่ม–ลดช่วงเลข แก้บรรทัดเดียวใน `index.html`

```js
houseNumbers: { prefix: "112/", from: 156, to: 307 }
```

## ระบบกันลงทะเบียนซ้ำ

ตรวจสอบจาก **เลขที่บ้าน + สถานะ** ร่วมกัน

| กรณี | ผลลัพธ์ |
|---|---|
| 112/296 เจ้าของบ้าน → ลงซ้ำ 112/296 เจ้าของบ้าน | ❌ บันทึกไม่ได้ |
| 112/296 เจ้าของบ้าน → ลง 112/296 ผู้อยู่อาศัย | ✅ บันทึกได้ |
| 112/296 → ลง 113/296 สถานะใดก็ได้ | ✅ บันทึกได้ |

- ตรวจ **2 ชั้น**: หน้าเว็บถามล่วงหน้าทันทีที่กรอกเลขที่บ้านและเลือกสถานะครบ (ผู้ใช้รู้ก่อนกรอกจนจบ) และตรวจซ้ำอีกครั้งที่ Google Sheets ตอนกดบันทึกจริง จึงกันกรณีสองคนกดพร้อมกันได้
- ข้อความที่ผู้ใช้เห็นจะบอกว่ามีคุณ "สมชาย ใ." ลงทะเบียนไว้เมื่อวันที่เท่าไร (ย่อนามสกุลเพื่อคุ้มครองข้อมูลส่วนบุคคล)
- ถ้าต้องการแก้ไขข้อมูลของบ้านที่ลงไปแล้ว ให้ลบแถวนั้นออกจาก Google Sheets แล้วให้ลูกบ้านกรอกใหม่

## รายละเอียดที่ออกแบบไว้เพื่อผู้สูงอายุ

- ตัวอักษรใหญ่ 20px เป็นค่าเริ่มต้น และมีปุ่ม **ขยายตัวอักษร** มุมขวาบน (ระบบจำค่าไว้ให้)
- ปุ่มและช่องกรอกสูง 60–64px กดง่าย ไม่พลาด
- ทีละขั้นตอน มีแถบบอกว่า "ขั้นตอนที่ 1 จาก 2"
- ข้อความบอกความผิดพลาดเป็นภาษาไทยชัดเจน พร้อมเลื่อนหน้าจอไปยังช่องที่ต้องแก้
- ช่องเบอร์โทรเปิดแป้นตัวเลขบนมือถือให้อัตโนมัติ และรับเฉพาะตัวเลข
- สถานะเจ้าของบ้าน/ผู้อยู่อาศัย เป็นกล่องใหญ่กดได้ทั้งกล่อง
- QR Code LINE ของหมู่บ้านจะแสดงหลังบันทึกข้อมูลสำเร็จ กดที่รูปแล้วเข้า LINE ได้ทันที
- ปุ่มบันทึกจะเป็นสีเทาพร้อมบอกว่า "เหลืออีกกี่ช่อง" จนกว่าจะกรอกครบ ถ้ากดทั้งที่ยังไม่ครบ หน้าจะเลื่อนไปยังช่องแรกที่ขาด
- ปุ่ม "กรอกข้อมูลให้บ้านหลังอื่นอีกครั้ง" สำหรับกรณีตัวแทนลูกบ้านช่วยกรอกให้หลายหลัง
- มีช่องดักบอทซ่อนไว้ กันสแปม

## สิ่งที่ตั้งค่าไว้เป็นค่าเริ่มต้น (แก้ได้)

- **อีเมลไม่บังคับกรอก** เพราะผู้สูงอายุหลายท่านไม่มีอีเมล — ถ้าต้องการบังคับ เปลี่ยน `requireEmail: true`
- เบอร์โทรรับ 9–10 หลัก (รองรับทั้งเบอร์บ้านและมือถือ)
- ข้อความ PDPA บนหน้าเว็บเป็นฉบับร่างตัวอย่าง รอแทนที่ด้วยฉบับจริง
